# 🌦️ Weather Forecast Web Application

A modern and responsive Weather Forecast Web Application built using React. This application provides real-time weather information, including temperature, humidity, wind speed, visibility, and weather conditions for any city around the world.

## 🚀 Features

* 🌍 Search weather by city name
* 🌡️ Current temperature display
* ☁️ Weather condition information
* 💧 Humidity details
* 👀 Visibility information
* 🌧️ Precipitation data
* 💨 Wind speed details
* 📱 Fully responsive design
* ⚡ Fast and user-friendly interface
* 🎨 Modern UI with weather icons

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6+)
* CSS3
* HTML5
* Weather API
* Axios (for API requests)

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/VEERAKURAGANTI/weather_forcast.git
```

### Navigate to Project Directory

```bash
cd weather_forcast
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will run on:

```bash
http://localhost:5173
```

## 🔑 API Configuration

Create a `.env` file in the root directory and add your Weather API key:

```env
VITE_WEATHER_API_KEY=your_api_key_here
```
